# Agent 录制执行手册

执行者：录制 Agent  
目标：由 Agent 完成浏览器操作和录屏，但成片呈现为一名真实会计在正常使用 Work，而不是自动化测试或技术演示。

## 一、总执行顺序

每条视频严格按以下顺序独立执行：

1. **预检**：确认网络、登录态、当前 Xero 公司、浏览器窗口和写入开关。
2. **无录屏彩排**：完整走一遍该条流程，确认真实数据和页面均正常。
3. **恢复起始状态**：新建对话；需要时恢复 Demo Company。视频 01 才允许安全断开专用 Work installation。
4. **录制 5 秒测试片**：确认没有通知、密码、其他标签页、AI 接管提示或调试高亮。
5. **开始正式录制**：画面静止 2 秒后再进行第一次操作。
6. **逐镜执行**：只按本手册点击、输入、等待和滚动，不临场增加测试。
7. **结束录制**：最终结果画面静止 3 秒，再停止录屏。
8. **立即验片**：按《04-成片验收与重录门槛》核对；不合格则整条重录。

不要在一条长视频中连续录三个流程。每条独立录制，便于重录和转发。

## 录屏工具设置

首选方式是在 OBS 中添加 `macOS Screen Capture`，捕获方式选择单个 Chrome 窗口：

- 画布与浏览器窗口统一为 1440×900，30fps；浏览器缩放 100%。
- `Show cursor` 开启，保留普通箭头；不添加点击动画或鼠标高亮。
- 只选择本次演示的 Chrome 窗口；`Show fullscreen and hidden windows / applications` 关闭。
- 麦克风、桌面音频、摄像头和通知全部关闭。
- 在彩排前配置开始/停止录制快捷键。正式录制时用快捷键控制，不把 OBS 窗口切到前台。

如果没有 OBS，使用 macOS `Shift–Command–5` 的“录制所选部分”，只框住浏览器页面区域，地址栏按需要排除。先录 5 秒测试片，检查菜单栏、录屏工具、AI 接管提示和桌面内容均未进入画面。

## 二、真人化操作规则

### 鼠标点击

- 只点击画面上看得见的文字、按钮、输入框或 Organisation 整行，不按隐藏 ID 或固定坐标盲点。
- 光标移动到目标用 0.3–0.6 秒；到达后停 0.3 秒，再单击一次。
- 点击后等待页面或控件稳定至少 1 秒，再做下一步。
- 不双击、不连续补点、不绕着按钮画圈，不把光标停在重要文字上。
- 选择 Organisation 时先点击整行或单选框，停 1 秒确认选中状态，再移动到绿色主按钮并点击。
- 保留普通箭头光标；关闭点击光圈、彩色轨迹、元素框选和自动化高亮。

### 输入提示词

- 短句少于 25 个字：以约每秒 5–8 个汉字的节奏输入。
- 长提示词：按真实办公习惯一次粘贴；粘贴后停 1 秒，快速检查输入框，再点击发送。
- 点击发送后，把光标移到右侧或下方空白区域，不停留在发送按钮上。
- 不输入工具名、接口名、Tenant ID、Organisation ID 或“调用只读工具”等技术语言。
- 如果输入错字，不在正式录制中反复修改；停止录制，重新开始该条。

### 等待 Agent 回答

- 回答生成期间不滚动、不点击、不展开工具详情。
- 保留 1–2 秒加载过程，让观众知道系统正在工作；之后安静等待回答完成。
- 必须等文字停止增长、加载状态消失，再开始展示答案。
- 原始工具 JSON、内部证据 envelope 和调试信息保持折叠；成片展示业务答案即可。
- 单次等待超过 30 秒、出现报错或页面断连时，停止录制，不在成片里刷新重试。

### 展示和滚动答案

- 回答不超过一个视口：不滚动，停留 3–5 秒。
- 回答超过一个视口：先让答案顶部完整停留约 3 秒，再每次向下滚动 280–420px，停留 2–3 秒后继续。
- 一次滚动只展示一个逻辑块；不要来回滚动，也不要快速拖动滚动条。
- 每个画面尽量同时保留该段小标题和对应数字，避免只看到半行金额或失去上下文。
- 最终停在最能表达业务价值的摘要或待办位置，静止 3 秒再进入下一轮提问。
- 如果答案超过约 2.5 个视口，停止录制；重新开新对话，在原提示词末尾补“控制在 8 行以内”后重录。

## 三、视频 01 逐镜执行

目标时长：60–90 秒。

| 镜头 | Agent 操作 | 画面节奏与检查 |
|---|---|---|
| 1. 起始画面 | 打开 Work 的 `Xero 会计助理`，保持页面静止 | 录制开始后静止 2 秒；不展示其他 Agent 或设置页 |
| 2. 发起连接 | 将光标自然移动到 Xero 连接按钮，停 0.3 秒，单击 | 等待新页面稳定；如果要求输入密码，立即停录，先在录制外完成登录准备 |
| 3. Xero 官方授权 | 确认地址与页面品牌属于 Xero，再单击官方主授权按钮 | 页面停留约 2 秒再点击；不展开权限说明，不展示密码管理器 |
| 4. 选择公司 | 在 zCloak AI 页面停留 2 秒；单击 `Demo Company (Global)` 整行，停 1 秒；再单击底部绿色主按钮 | 必须清楚看见官方圆形 Xero Logo、Organisation 名称和选中状态；不选择 zcloak |
| 5. 回到 Work | 等页面返回并稳定，点击新对话输入框 | 不连续刷新，不打开 MCP 调试信息 |
| 6. 输入业务问题 | 粘贴：`先告诉我现在连的是哪家公司、本位币是什么。先别动账。`；停 1 秒，发送 | 这是会计业务表达，不额外解释 OAuth 或 MCP |
| 7. 展示结果 | 等回答完成；把光标移到空白处 | 同时看见 `Demo Company (Global)` 和 USD；停 4 秒后结束录制 |

若 Xero 同意页没有出现、直接进入组织选择页，可以继续录制，但成片标题改为“连接并选择公司”，不要声称本条展示了完整首次 OAuth。

## 四、视频 02 逐镜执行

目标时长：2–3 分钟。

| 镜头 | Agent 操作 | 画面节奏与检查 |
|---|---|---|
| 1. 起始画面 | 新建 Work 对话，空白会话静止 2 秒 | 当前 Organisation 必须已在彩排后确认是 Demo Company |
| 2. 第一轮提问 | 粘贴：`我刚接手这个客户。先确认一下是哪家公司，然后帮我看看最近可用日期的应收应付，挑三件今天最值得我先复核的事。拿不准的地方直接说拿不准，先别动账。`；停 1 秒，发送 | 不改写成测试语言；生成期间不滚动 |
| 3. 展示快速体检 | 回答完成后，从答案顶部开始展示；需要时按 280–420px 分段慢滚 | 必须看见公司/币种、真实客户或供应商、金额和为什么值得复核；总展示控制在约 12 秒 |
| 4. 追第一项 | 回到底部输入框，输入：`把刚才排第一的那一笔再展开一下。它什么时候到期、现在还差多少、有没有相关付款或 Credit Note？给我一个简短结论就行。` | 使用“刚才排第一的那一笔”，不要临时复制内部 ID |
| 5. 展示单据追踪 | 等回答完成；答案顶部停 3 秒，必要时只滚一次 | 必须看见到期日、未结金额，以及付款/Credit Note 是否查到；没有证据时应明确说没查到或拿不准 |
| 6. Trial Balance | 输入：`再看一下最近可用的 Trial Balance。只告诉我两三项值得复核的地方，不要因为借贷相等就说已经完成对账或可以关账。` | 长句一次粘贴，停 1 秒后发送 |
| 7. 收口画面 | 等答案完成；展示查询日期、范围、事实和待复核项 | 不展开工具详情；最终摘要静止 4 秒后结束 |

如果第一轮回答没有具体金额、单据或复核理由，直接停止录制并重新开新对话，不在镜头内教 Agent 补救。

## 五、视频 03 逐镜执行

目标时长：90–120 秒。

| 镜头 | Agent 操作 | 画面节奏与检查 |
|---|---|---|
| 1. 起始画面 | 新建 Work 对话；输入：`这个客户先看到这里，我要换另一家公司继续做。给我选择入口就行，先不要改任何账。` | 长句一次粘贴，停 1 秒后发送 |
| 2. 打开入口 | 等短效链接出现；光标移动到链接，停 0.4 秒，单击一次 | 不复制 URL，不展示完整 ticket，不右键打开菜单 |
| 3. 展示选择页 | 页面稳定后静止 2 秒 | 必须看见官方 Xero Logo、当前 Demo Company 和两个可用 Organisation |
| 4. 选择新公司 | 单击预先批准的 `zcloak` 整行，停 1 秒确认选中；再单击底部绿色主按钮 | 不触碰当前 Demo Company 行，不双击按钮 |
| 5. 回到对话 | 等返回 Work 后，输入：`好了。重新确认一下现在是哪家公司和什么币种，然后只看这个公司的数据。` | 必须让 Agent 重新读取，不能沿用旧回答 |
| 6. 展示回读 | 等回答完成，把光标移到空白处 | 必须看见 zcloak 和 HKD；静止 4 秒后结束 |

录制停止后，Agent 在录制外用同样流程切回 `Demo Company (Global)`，再回读 USD，并填写录制日志。恢复失败不得交付视频。

## 六、必须立即停录的情况

- 出现密码、Token、Secret、Tenant ID、完整 ticket、私人通知或无关标签页。
- 画面出现 AI 接管提示、自动化边框、点击光圈或调试面板。
- Agent 读到的 Organisation 与该视频规定不一致。
- 回答仍在生成时误滚动，或工具调用报错、OAuth 失败、页面断连。
- 回答把有限查询说成完整审计、已完成银行对账、可以关账或已经写入。
- 光标抖动、连点、来回滚动，或者重要金额被截断。
- 任何 Xero create、update、approve、pay、reconcile、delete 或 void 被调用。

正式录制里不做错误恢复。停录、保存问题原因、恢复正确起始状态，再重新录该条。

## 七、Agent 交付内容

每条录完后交付：

1. 对应 MP4 文件；
2. Work 对话链接；
3. 实际开始和结束时间；
4. 起始与结束 Organisation；
5. 是否出现写入工具调用，必须为“否”；
6. 是否通过隐私、业务答案、画面节奏和恢复检查；
7. 视频 03 切回 Demo Company / USD 的回读记录。

填写 `materials/Agent录制日志模板.md`，验收通过后再将文件交给产品负责人。
