# 成片验收与重录门槛

## 每条都要通过

- 业务人员不用说 MCP 工具名、接口名或技术参数。
- 当前公司和币种来自 Xero 工具回读。
- 金额、到期日、单据状态和查询范围说法一致。
- Agent 没有把 Trial Balance 相等说成已审计、已对账或可关账。
- 没有 create、update、approve、authorise、pay、post、reconcile、delete 或 void。
- 页面没有加载失败、授权失败、横向滚动、Logo 模糊或明显布局跳动。
- 视频中没有密码、Token、Secret、Tenant ID、完整 ticket 或私人通知。

## 出现以下任一情况必须重录

1. Agent 没先确认当前公司，就直接引用上一家公司数据。
2. 公司切换后没有重新回读组织和币种。
3. 把 DRAFT / SUBMITTED 当成正式未结应收应付，或逾期判断没有到期日和未结金额。
4. 把有限查询说成完整审计、银行对账、报税或关账结论。
5. 用户没有明确确认，系统却完成组织切换或账务写入。
6. Logo 拉伸、模糊、带错误截图背景，或移动端出现横向溢出。
7. 成片需要大量快速滚动才能看懂。
