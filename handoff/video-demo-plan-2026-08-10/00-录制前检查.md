# 录制前检查

## 1. 演示环境

- 使用 Work 正式环境和 `Xero 会计助理`。
- 使用 Xero Demo Company 或专用测试公司，不使用真实客户账套。
- 确认 MCP 健康状态正常、版本为 `0.3.1`、工具数为 44。
- 确认写入开关关闭；本次仅做读取、分析和公司切换。
- 预先确认两个可授权组织都允许出现在视频中。

## 2. “重置”分两级

### 轻量重置（视频 02、03 使用）

1. 新建一个 Work 对话。
2. 保留现有 Xero 连接，不清 Token、不撤销授权。
3. 先让 Agent 回读当前公司和币种，避免沿用上一段上下文。

### 完整重置（视频 01 才使用）

1. 只在专用演示 OAuth client / installation 上断开连接。
2. 不在 Xero Developer Portal 删除正式应用，也不撤销其他 Host 的授权。
3. 重新点击连接，走 Xero 官方 OAuth，再进入组织选择页。
4. 录制完成后重新确认 Work 仍绑定 Demo Company。

如果录制人员不熟悉 OAuth installation，视频 01 由产品或开发陪同录制；不要为了“像首次使用”临时删除服务端数据。

## 3. 画面与隐私

- 首选 OBS 的 `macOS Screen Capture`，模式选择单个 Chrome 窗口，`Show cursor` 开启，隐藏窗口关闭，麦克风和桌面音频关闭。这样只录 Work/Xero 浏览器，不录 Agent 控制界面。
- 如果电脑没有 OBS，使用 macOS `Shift–Command–5` 的“录制所选部分”，框选浏览器页面区域；开始和停止控件放在框外。
- 浏览器和录制画布建议统一为 1440×900、30fps，浏览器缩放 100%，不要在录制过程中改变窗口大小。
- 关闭通知，隐藏书签栏和无关扩展图标。
- 只捕获目标浏览器窗口；不要录整个桌面。
- 保留普通箭头光标，让观众能看懂点击路径；关闭点击光圈、自动化高亮、调试边框和 AI 接管提示。
- 录制前先录 5 秒测试片，确认画面里只有浏览器内容和普通光标。若 AI 接管提示进入画面，停止正式录制，改为浏览器窗口捕获或调整裁切范围。
- OAuth 登录时不要展示密码输入或密码管理器弹层；可从已登录的 Xero 组织同意页开始录。
- 公司选择页的 URL 含短效 ticket。成片应裁掉地址栏，或在后期打码。
- 录制声音不是必需；建议先录无声画面，再根据老板需要补 20–30 秒旁白。

## 4. 录制前冒烟检查

依次确认：

1. 新会话能读出 `Demo Company (Global)` 和 USD。
2. 应收、应付和 Trial Balance 工具能返回结果。
3. “我要换公司”能生成一次性入口。
4. 公司选择页显示官方圆形 Xero Logo，桌面和移动端都不糊、不变形。
5. 当前 Work 会话没有任何 create、update、approve、pay、reconcile 或 delete 调用。
6. Agent 已完成对应视频的无录屏彩排，并已恢复到该视频规定的起始状态。
