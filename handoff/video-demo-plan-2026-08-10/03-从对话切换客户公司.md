# 视频 03：从对话切换客户公司

建议时长：90–120 秒  
核心信息：会计事务所处理多个客户时，不需要理解 MCP 设置；在对话里说要换客户即可获得安全入口，真正切换仍由用户明确确认。

本条必须由执行 Agent 按《05-Agent录制执行手册》中的“视频 03”逐镜操作。只点击预先批准的演示组织；录制后按手册恢复 Demo Company。

## 起始状态

- 新建 Work 对话。
- 当前组织为 `Demo Company (Global)`。
- 第二个演示组织已事先确认允许出镜。

## 录制步骤

1. 先发送：

> 这个客户先看到这里，我要换另一家公司继续做。给我选择入口就行，先不要改任何账。

2. Agent 返回一次性链接；点击进入组织选择页。
3. 停留 2 秒展示：当前公司、两个可用组织、官方 Xero Logo。
4. 选择预先批准的第二个演示组织并确认。
5. 回到原对话发送：

> 好了。重新确认一下现在是哪家公司和什么币种，然后只看这个公司的数据。

6. Agent 回读新公司和币种后结束。

## 成片必须看见

- 只说“换公司”不会静默切换；Agent 只给入口。
- 用户必须在页面上明确选择并确认。
- 确认后 Agent 再从 Xero 回读新组织，不能沿用旧会话中的公司名称。

## 录后恢复

用同一流程切回 `Demo Company (Global)`，再回读公司和 USD。恢复动作可不放进成片，但必须记录在录制日志中。
