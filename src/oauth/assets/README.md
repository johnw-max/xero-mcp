# Brand asset provenance

`xero-logo.png` is the unmodified 1000 x 1000 transparent high-resolution
PNG from Xero's official logo pack.

- Official media page: https://www.xero.com/us/media/downloads/
- Official asset pack: https://www.xero.com/content/dam/xero/downloads/accountants-and-bookkeepers/partner-toolkit/xero-logos-images.zip
- File inside the pack: `Xero logos/Screen/Standard/xero-logo-hires-RGB.png`

Use the asset without recolouring, cropping, stretching, or adding text inside
the mark. The page controls only its rendered size and keeps the original file
resolution for high-density displays.
